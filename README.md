A from-scratch limit order book and matching engine enforcing strict **price-time priority**: best price wins, earliest arrival breaks ties. Built for determinism and predictable latency.

```text
 ORDER IN ──▶ [ VALIDATE ] ──▶ [ BOOK  bids ▼ │ asks ▲  (per price level, FIFO) ]
                                              │
                                              ▼
                              [ MATCH  price ▸ time ] ──▶ FILLS / ACKS OUT
```
